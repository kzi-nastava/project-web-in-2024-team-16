# 🛒 Buy & Sell Platform (Kupujem Prodajem Clone)

## 📌 Overview
A simple marketplace web application inspired by “Kupujem Prodajem”, allowing users to post, browse, and manage product listings.

## 🛠️ Tech Stack
- Backend: Spring Boot  
- Frontend: Vue.js  
- Database: H2 (in-memory database)

## 🚀 Notes
This project was developed as a learning exercise to practice full-stack development with Spring Boot and Vue.js.
